### 18. `app/api/trpc/[trpc]/route.ts`
**Путь:** `/app/api/trpc/[trpc]/route.ts`  
**Назначение:** Endpoint для tRPC запросов

#### 🔹 Реализация:
```tsx
import { fetchRequestHandler } from '@trpc/server/adapters/fetch';
import { appRouter } from '../../../../server/trpc';
import { createContext } from '../../../../server/trpc/trpc';

const handler = (req: Request) =>
  fetchRequestHandler({
    endpoint: '/api/trpc',
    req,
    router: appRouter,
    createContext,
  });

export { handler as GET, handler as POST };
```

#### 🔹 Как работает:
1. Next.js создаёт маршрут `/api/trpc/[...trpc]`
2. Все запросы идут через `fetchRequestHandler`
3. `createContext` добавляет БД и пользователя в контекст
4. tRPC роутит запрос к нужной процедуре

  // Проверка сессии
  const session = await db.query.gameSessions.findFirst({
    where: eq(gameSessions.id, sessionId)
  });
  
  // Получение ботов
  const bots = await db.select().from(gamePlayers)
    .where(and(eq(gamePlayers.sessionId, sessionId), eq(gamePlayers.isBot, true)));
  
  // Запуск ботов
  for (const bot of bots) {
    const gameBot = BotFactory.createBot(sessionId, bot.id, difficulty);
    await gameBot.startFindingWords();
  }
  
  // Сохранение статистики
  await saveMatchHistory(sessionId);
}
