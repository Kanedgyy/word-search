# Руководство пользователя

## Установка и запуск

### Требования
- Node.js 18+
- PostgreSQL 14+

### Шаги установки

1. Установите зависимости:
```bash
npm install
```

2. Создайте базу данных PostgreSQL:
```bash
psql -U postgres
CREATE DATABASE word_search;
```

3. Настройте переменные окружения в `.env.local`:
```env
DATABASE_URL=postgresql://localhost:5432/word_search
```

4. Создайте миграции:
```bash
npm run db:generate
npm run db:migrate
```

5. Запустите приложение:
```bash
npm run dev
```

6. Откройте http://localhost:3000

## Как играть

### Создание игры

1. Введите ваше имя на главной странице
2. Нажмите "Создать новую игру"
3. Скопируйте ID сессии (отображается в URL)
4. Поделитесь ID с друзьями

### Присоединение к игре

1. Введите ваше имя
2. Введите ID сессии
3. Нажмите "Присоединиться к игре"

### Управление игрой

**Для хоста:**
- "Начать игру" — запускает игру (нужно минимум 2 игрока)
- "Добавить бота" — добавляет ИИ-игрока

**Для всех игроков:**
- Выделяйте слова мышью: нажмите на первую букву и протяните до последней
- Слова могут быть горизонтально, вертикально и по диагонали
- Найденные слова вычёркиваются из списка

### Командный режим

1. Перед началом игры выберите команду (если доступно)
2. Игроки одной команды суммируют очки
3. Побеждает команда с наибольшим счётом

### Режим тренировки (с ботами)

1. Создайте игру
2. Добавьте одного или нескольких ботов
3. Начните игру
4. Боты будут находить слова с заданной скоростью

## Правила

- **Цель:** Найти как можно больше слов за отведённое время
- **Время:** 5 минут (может быть изменено хостом)
- **Победитель:** Игрок с наибольшим количеством слов
- **При равенстве:** Учитывается скорость нахождения первого слова
- **Одно слово:** Может быть найдено только одним игроком
